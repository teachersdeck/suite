# teachersdeck/suite

TeachersDeck Suite's website moved to **https://myteachersdeck.com** (source: [teachersdeck/site](https://github.com/teachersdeck/site)).

This repo only keeps the old `teachersdeck.github.io/suite/...` addresses working: every page it had forwards to the same page on the new domain, and any other address (old PDFs, sitemap) is forwarded by `404.html` with its path kept.
